# 连接故障日志

连接诊断默认开启，记录原生状态轮询、会话读取、历史分页、事件批次、握手及 Codex 上游失败。网页服务启动和收到退出信号时也会记录版本、进程身份和生命周期事件，用于区分维护重载与链路故障。正常轮询不逐条写日志；相同原因会合并，恢复记录包含累计失败次数和中断时长。

浏览器请求和网页服务、Codex bridge 共用 `X-Agent-Web-Trace-ID`。按同一个 `traceId` 能对照失败发生在浏览器到网页服务，还是网页服务到执行端。`authentication_expired` 表示服务端确认会话签名有效但已过期；`request_timeout`、`connection_refused`、`connection_reset`、`dns_error`、`rate_limited` 分别保留对应原因。`request_cancelled` 也可能是正常切换页面，应与浏览器超时及取消记录一起判断。

## 查看与下载

在已经登录的网页同一域名访问 `/api/diagnostics/connections`，可查看最近 100 条事件、实际日志路径和轮换配置。访问 `/api/diagnostics/connections?download=1` 下载最近日志 JSON。接口沿用现有认证和同源检查，不在链接中传密码或令牌。

服务端文件默认为 `<Pi agent 目录>/logs/connections/<主机名>.jsonl`。每个文件上限 2 MiB，另保留两份轮换文件，总量约 6 MiB。文件权限设为当前账户私有；日志目录可由维护环境变量 `PI_WEB_DIAGNOSTICS_DIR` 指向专用目录。

网页服务无法访问时，浏览器在当前站点的本地存储中暂存最近 24 小时内至多 80 条脱敏记录；恢复后由正常请求成功、重新联网或页面回到前台触发补交，不新增永久轮询。浏览器丢失本地存储或清理站点数据后，未送达记录也会被清除。

## 字段边界

记录时间、引擎、会话 ID、标签页 ID、接口模板、HTTP 状态、错误分类、耗时、超时预算、失败次数、在线及前后台状态和版本。路径中的动态段和查询参数会被移除。不会保存对话正文、附件、响应正文、原始错误字符串、Cookie、Authorization 或密码。客户端不能伪造服务端记录或运行元数据。

此日志用于还原后续故障，不保证能恢复安装前没有采集到的浏览器原因。底层连接功能、发送回执与任务队列继续由原有责任组件维护。
