# 内置自动复盘

本说明对应包含自动复盘的 main 源码，源码构建出的安装包自带此功能，无需群晖私有插件。旧的 v1.3.74 发行包不包含，需要源码构建或后续发行包。打开原生「设置 → 自动复盘」启用，默认关闭。

启用后，普通项目会话完成包含至少两次工具结果、工具失败或明确纠正的任务时，会以该会话当前模型及凭据进行一次后台复盘。普通闲聊和子代理不触发。后台复盘不会修改原会话的模型、工具权限，也不会把复盘结果追加到聊天记录。

## 使用闭环

1. 完成真实任务；后台记录复盘状态，不阻塞下一条消息。
2. 在「自动复盘」中手动刷新查看结果。经验按项目真实路径隔离。
3. 下次相关任务开始前，最多读取三条启用经验，作为不可信历史参考；经验不能替代当前授权或验证。可以停用不准确的记录。
4. 技能建议保持「待确认」。先预览正文，再点击「采用为项目技能 → 确认采用为项目技能」。只写入当前项目 `.pi/skills/pi-web-learned-<标识>/SKILL.md`；不同的已有内容不会被覆盖。新会话或重新加载后由原生技能加载器读取，仍遵守项目信任机制。

## 成本、隐私和限制

每次复盘输入最多 12000 字符、输出最多 800 tokens、30 秒超时；全实例串行，每项目每小时最多 10 次，全局队列最多 20 项。原会话的模型服务商会收到经过常见凭据规则过滤的文本片段；图片和工具参数不传入。自动过滤不能保证识别任意格式的秘密，不希望历史片段发送到模型时请保持关闭。

记录保存在 Pi 的 agent 目录下 `learning/settings.json` 和 `learning/projects/<真实目录哈希>.json`，使用原子写入和文件锁。每项目最多 100 条经验，复盘状态保留最近 40 条。重复经验累计次数，不会重新启用已停用内容。记录包含复盘标识、来源会话和模型；关闭开关会取消当前复盘并跳过排队任务。超时、预算不足和模型错误会显示实际状态，不自动重新调用模型。重启后遗留状态会标为中断，不重放旧任务。

这是任务经验的积累与检索，以及经确认的技能生成。它不会自行修改产品源码、绕过权限、修复生产环境，也不能保证以后不再出错。首次启用建议先审阅生成的经验质量。
