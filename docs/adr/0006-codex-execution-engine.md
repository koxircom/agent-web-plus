# 0006：可选 Codex 执行引擎

状态：候选，须以对应版本的真实浏览器与执行端验收收据为准。

Pi 原生 React 组件拥有会话展示、输入、图片编辑、草稿、滚动和重连；Codex 服务端适配器拥有连接认证、协议转换和远端路径路由。连接器拥有执行进程、持久化提交、队列串行判断和项目文件边界。浏览器不导入 Bridge 前端，也不承担执行端心跳或任务寿命。

默认引擎是 Pi。Codex 设置独立私有保存，配置读取脱敏。Codex 会话使用 `codex:<UUID>`；显式会话 ID 先于默认引擎决定历史、命令和附件来源。更换连接配置使旧投影失效，禁止将原执行端的轮询或操作转发到新地址。新会话与默认引擎切换清理当前原生视图，不转换历史。

浏览器使用已有 Pi SSE，服务端每个被观看会话共享一个 Bridge 增量长轮询；关闭网页释放投影，不结束 Codex 任务。初始页面不等远程后端；默认 Pi 且 Codex 关闭时无远端请求。列表运行状态只查询元数据，历史分页与工具大正文按需读取。

提交先写 Pi 的持久化投递收据，再使用确定的 Codex submission UUID。执行端持久化后确认；断网或服务端错误导致结果不明时保留 unconfirmed，不自动重发。拒绝与不明必须区分。自动排队在执行端锁内判断，不能相信前端瞬时的 running 状态。

普通文件 API 按配置根路径最长边界映射，随后由连接器再次拒绝路径逃逸与符号链接；不访问网页主机的对应路径。不同内容同名上传不能覆盖。所有有写入的验收必须限定独立工作区及数据目录；原聊天只读验收不能代替新消息、附件或重连后完整消息的验收。

## 连接恢复契约

事件流由原生 AgentEventConnection 单独拥有。服务端每15秒发送可观测心跳，浏览器75秒无有效事件则关闭旧流并重新握手；心跳不进入消息状态。自动重连按1/2/4/8/10秒退避，成功握手后复位，关闭或切换会话会取消旧计时器。恢复后的原生快照/历史校准沿用现有机制。页面online/pageshow复用租约检查，不建立第二套重连所有者。

Bridge认证过期时，GET读取可共享一次重新登录并重试一次；迟到的旧401不得清除新认证。发送、上传、队列及审批的POST仍遵守原投递收据，不由连接层重放。

会话列表modified优先使用Bridge的毫秒recency（真实交互时间），缺失时才使用秒updatedAt；标题、索引等元数据维护时间不覆盖交互时间。
