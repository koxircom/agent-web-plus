# Agent Web Plus 1.4.49 发布说明（上线候选 / Release Candidate）

> **状态声明**：当前版本为 **1.4.49 上线候选（Release Candidate）**，仅完成源码与版本维护，**尚未部署到正式或测试运行环境**；明确不声称 Android 真实 OS 弹层验证，不声称 Windows 已升级。

## 本次核心维护与边界修复

1. **媒体过滤与独立文件/流支持（Media Filter & Android Octet）**
   - 修复附件选择器中的媒体类型过滤（图片与 video 媒体 filter），区分媒体类型与通用独立文件。
   - 优化 Android 平台下的二进制流附件（`application/octet-stream`）与独立文件处理，避免类型误判与选择器异常。

2. **附件取消保护与单一所有权治理（Cancel Guard & Single Owner）**
   - 修复 Picker 取消时的回归缺陷，保证用户在系统选择器中取消选择时不丢失既有附件与草稿状态（取消不丢）。
   - 确立附件与输入状态的单一所有者（单 owner）调度，杜绝跨模块/跨进程状态竞争与重复所有权覆盖。

## 验证与边界说明

- 本次变更严格聚焦于文件选择器（Picker regression）与附件生命周期边界收敛。
- 明确声明未在 Android 真实操作系统弹层上进行真机验证，Windows 端未执行升级部署。
