# Agent Web Plus 1.4.2

在同一个网页中切换 Pi Agent 与 Codex，使用各自的会话、工作区和执行能力。

## 本次更新

- 修复 Codex 会话添加附件时的工作区路径错误，覆盖已有会话与新会话。
- TXT、日志、代码等上传文件保留为附件；预览不会将内容展开到消息正文。
- 改进任务完成、重新打开会话后的最终答复同步。
- 修复完成回填时追加用户消息与引用的位置错乱，保留消息身份和原始位置。
- 改进需要用户操作时的提示与入口。

## 安装或升级

下载下方 `pi-web-plus-1.4.2.tgz`，然后执行：

```bash
npm install -g ./pi-web-plus-1.4.2.tgz
agent-web
```

需要 Node.js 22.19 或更高版本。原 `pi-web` 命令继续可用；保留旧配置目录的兼容读取，升级后继续使用原会话、置顶和设置。

Codex 需要单独安装并登录 Codex CLI，然后在设置的“执行引擎”中配置项目内置的 Codex 执行端。安装和配置说明见 [README](https://github.com/koxircom/agent-web-plus/blob/v1.4.2/README.md) 与 [Codex 执行引擎文档](https://github.com/koxircom/agent-web-plus/blob/v1.4.2/docs/codex-engine.md)。
