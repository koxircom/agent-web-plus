# Agent Web Plus 1.4.61

本次发布包含完整应用，累计更新到维护版 **1.4.61.8**，四个 Pi Agent SDK 均固定为 **1.5.0**。网页主版本和正式 Git 标签仍为 `1.4.61` / `v1.4.61`。

## 本次更新

- Pi Agent SDK 升级到 1.5.0，统一原生 Agent 调度入口，修复后台任务结果交付与兼容迁移。
- 批量删除显示具体失败原因；已完成的提示可向左或向右清理，进行中的作业保留保护。
- 进入选择模式保留会话标签、模型、思考深度、任务状态和行高；修复触摸单击勾选后立即回退，保留连续滑选及回滑撤销。
- 新增原生浏览器标签页设置：`{project}`、`{agent}`、`{text}`、`{app}` 模板、自定义文本、Logo 颜色和浏览器主题色，支持保存、刷新及跨浏览器同步。
- 改善多窗口并行流式输出、刷新后的进行中会话恢复、短请求交付、弱网发送可见性和拒绝后的草稿恢复。
- 文件页保留原始 Pi/Codex 引擎上下文；Codex 文件监听按面板可见性启用，文件外部变动能自动更新。
- 修复终端标签/输出恢复、队列拖动排序与计时、触摸操作及设置相关回归。
- 包含此前主分支版本以来的原生界面、文件、图片编辑、会话状态、标签和兼容性修复；源码为完整版本快照。

## 安装与升级

下载完整的 `agent-web-plus-1.4.61.tgz`，按随附 `INSTALL.zh-CN.md` 安装。它包含预构建 Next.js 应用、静态资源、命令入口、Codex connector、运行时扩展及第三方声明；无需在用户机器重新构建前端。npm 会安装声明的依赖。本次不是增量补丁，也不是离线依赖全集。

配置入口为“设置 → 常规 → 浏览器标签页”；已有“常规”快捷项时可以直接进入。

## 已知能力边界

- 桌面 Chrome 不允许网页控制单个标签的背景色。`theme-color` 作用于支持它的浏览器工具栏或 PWA，Logo 颜色可独立配置。
- Windows CDP 未产生原生长按选区；必要触控门禁通过，原生手势由 Android 真机覆盖。
- 图像测试验证传输、草稿与持续可见性，不代表图像语义模型能力。
- Codex 引擎沿用其既有能力，不提供 Pi 专有的网页终端。
