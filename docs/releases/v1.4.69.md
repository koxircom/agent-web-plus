# Agent Web Plus 1.4.69

## 更新

- 优化自动复盘设置的桌面与手机排版，显示开关、项目记录和 Pi Agent 适用范围。
- 精简增强插件设置：基础优化默认生效，保留有实际个性化选择的设置。
- 文件浏览器默认隐藏，可在常规设置中启用。

自动复盘默认关闭，仅支持 Pi Agent 会话；符合条件的任务会使用会话模型进行限量后台复盘，可能产生额外费用。经验按项目保存，技能候选须经用户确认后采用。

## 版本与安装

- Web：1.4.69；维护版本：1.4.69.1；Pi Agent SDK：1.5.0。
- 需要 Node.js 22.19.0 或更新版本。安装包包含应用及构建资源，依赖在安装时按平台下载，并非离线依赖镜像。
- 升级前保留原数据目录、配置和服务启动方式；安装后核对版本及原有会话。
