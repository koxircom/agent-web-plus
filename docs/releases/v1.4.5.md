# Agent Web Plus 1.4.5

本次发布汇总 1.4.3 至 1.4.5 的 Codex 交互、会话管理和图片标注修复。Pi Agent 与 Codex 继续共用同一套网页组件，旧命令、会话目录、置顶与设置保持兼容。

## 更新内容

### Codex 提问与回答

- 接通 Codex 提问的网页回答入口，支持预设选项与自定义回答，并按原生问题 ID 回传。
- 扩大提问卡片的正文区域；手机输入框与操作按钮统一为 44px，长问题可滚动，键盘展开后仍可操作发送按钮。
- 修复回答后误显示内部标签、JSON 与问题 ID 的问题。历史消息与即时发送确认统一显示为“问题／回答”，传输原文和消息身份保留。
- 回答发送失败时保留输入内容，重新打开页面后可恢复仍待处理的问题。

### 手机会话管理

- Codex 会话可在手机网页中二次确认后删除，原生记录与网页索引同步处理。
- 未确认消息和待发送队列会阻止删除，并显示具体原因。
- 修复删除与发送并发时的锁顺序，保持 Pi 原有删除流程兼容。

### 图片标注

- 修复中断或取消标注后残留的临时红框被带入导出图片的问题。

## 安装与升级

需要 Node.js 22.19 或更高版本。从本 Release 下载 `pi-web-plus-1.4.5.tgz`，再运行：

```bash
npm install -g ./pi-web-plus-1.4.5.tgz
agent-web
```

旧命令 `pi-web` 继续可用。升级前保留现有数据目录；升级沿用原会话、置顶和设置，不需要重新创建。

首次使用 Codex 时，请按 [Codex 执行引擎配置](https://github.com/koxircom/agent-web-plus/blob/v1.4.5/docs/codex-engine.md) 配置自己的 Codex CLI、认证和工作区。项目提供执行端适配器，Codex CLI 与模型认证由使用者自行配置。

项目 README 中的介绍视频可以直接在线播放。

## 验证与限制

- 已通过受影响检查、Pi/Codex 手机尺寸浏览器检查、生产构建与安装包发布关卡。
- 发布源码、说明和实际安装包经脱敏扫描；上传后下载回读并核对 SHA256。
- 尚未实现已打开旧标签页的安全自动版本切换；升级后需重新加载旧页面以使用新界面。
- 个别手机页面曾未显示提问的预设选项，具体触发原因尚未确认；本版不将该次异常标为已修复。实体手机仍需进一步复测。

附件 `SHA256SUMS` 提供安装包校验值。
