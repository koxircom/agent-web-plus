# Pi Web v1.4.95 发行说明

## 变更概述

1. **目标卡片置于队列上方且零重叠**：
   - 调整输入框上方组件的 DOM 渲染拓扑顺序，将目标卡片宿主（`.chat-composer-goal-host`）置于排队消息卡片（`ComposerQueue`）的上方；
   - 增加独立的下边距 `margin-bottom: 8px` 与清晰的垂直流式堆叠，杜绝目标卡片与排队卡片重叠遮挡。

2. **目标删除按钮复刻队列垃圾桶双击确认逻辑**：
   - 将目标卡片末尾的原“删除”文字按钮替换为与排队队列完全一致的垃圾桶图标（`<ComposerQueueIcon kind="delete" />`）；
   - 复刻队列删除的双击确认逻辑：第一次点击进入确认状态，按钮高亮变红、title 提示“再次点击确认删除目标”，3.5 秒未操作自动超时恢复；在 3.5 秒内第二次点击才真正执行目标删除并退出目标模式。

3. **目标暂停按钮替换为音乐播放器风格并支持悬停变红**：
   - 将原“暂停”文字按钮升级为音乐播放器标准暂停双竖线图标（`Pause` SVG）；已暂停态显示播放三角形图标（`Play` SVG）；
   - 增加 `:hover` 悬停红色高亮效果（`color: #ef4444` 及对应红晕边框与半透明背景），尺寸统一为 28x28px 工具按钮。
