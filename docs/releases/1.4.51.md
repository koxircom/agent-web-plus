# Agent Web Plus 1.4.51 发布说明（上线候选 / Release Candidate）

> **状态声明**：当前版本为 **1.4.51 上线候选（Release Candidate）**，合并 1.4.50 未上线候选与附件选择器修复（1.4.50 从未上线 host，因 WAITING_IDLE 30m 结束 FAILED 无 cutover，当前生产环境仍为 1.4.49）；保留 `1.4.50.md` 作候选历史无需删除。明确本轮验证基于仿真与协议断言，**未在实体手机硬件上进行测试**；**可不保证 OS appearance 系统外观完全一致**。

## 本次核心维护与边界修复

1. **三指跨区防误开与手势隔离（1.4.50 候选合并）**
   - 修复多指竞争缺陷，建立多指污染状态跟踪，隔离直至全指离开。
   - 针对跨屏幕区域的三指滑动进行严格手势隔离，杜绝系统级多指操作误拉出右侧会话导航抽屉（三指跨区防误开）。
   - 严格保留空白区域单指双击与常规单指左右滑动、底栏工具栏手势交互。

2. **恢复旧优先文件选择器 API（Document showOpenFilePicker API 恢复）**
   - 恢复 `document` 级别 `showOpenFilePicker` 旧优先 API 调度，优化跨平台文件选择兼容性。
   - 严格处理安全上下文边界：在非安全上下文（Secure Context Required）下自动降级到常规 input 机制（HTTP fallback）。

3. **用户取消防二次回退与原生分流（Abort, Native Stream Routing & Late 隔离）**
   - **Abort 不会二次 fallback**：捕获用户取消（AbortError）时不触发二次 fallback，杜绝误弹多余选择框，不丢失既有附件与输入草稿。
   - **图片文档原生分流**：区分媒体与通用文件，实现图片与文档的原生分流处理与 Android 二进制流解析。
   - **Late 隔离与单一所有者**：对异步迟到（late）的选择结果与事件进行生命周期隔离，确保附件与输入调度具备单一权威所有者（Single Owner）。
