# Agent Web Plus 1.4.55 发布说明（上线候选 / Release Candidate）

> **状态声明**：当前版本为 **1.4.55 上线候选（Release Candidate）**。1.4.54 处于待 idle 状态，未执行生产环境正式上线切换（no cutover），当前生产环境旧版本仍为 1.4.49。保留先前候选版本（1.4.50、1.4.51、1.4.52、1.4.53、1.4.54）发布历史，依赖（deps）历史不作破坏性改动。

## 本次核心维护与边界规范

1. **输入框右下角发送按键与队列徽标优化（Send Button & Queue Badge Polish）**
   - **纯净向上箭头圆圈（White Circle Up Arrow）**：右下角发送及后续消息按钮统一采用 Cursor 风格圆形向上箭头（Up Arrow），去除旧版按钮上的数字徽标（去数字 badge）；
   - **队列行为与排队列表完整保留（Queue Behavior & Queued List Preserved）**：不改变任何底层队列机制（steer/followup/sendQueued），完整保留 ComposerQueue 队列管理面板与任务排队列表；
   - **主题对比度自适应与禁用态（Theme Contrast & Disabled Invariant）**：暗色模式（Dark）下为白底黑箭头（White circle / Black arrow），亮色模式（Light）下反转为深色底白箭头以确保清晰可辨；禁用态（Disabled）保持合理的透明度与不可用光标。

2. **保留既有候选不变量与边界规范（Preserved Invariants & Boundaries）**
   - **保留 Usage（1.4.54 用量治理与安全所有者锁）**：外部扫描与合并防丢用量，Web 异步无感调度，Seal/Fingerprint/Tombstone 一致性严格不放宽；
   - **保留 Title（1.4.53 浏览器标签自定义标题）**：通用设置支持自定义标签标题（`pi-browser-tab-title`），同源本地隔离，最高优先级且固定不被状态覆盖；
   - **保留 Goal 与 Image（1.4.52 控制流与图片回写）**：任务控制流先 State 后 Ctx Abort，Idle 冻结挂起不误杀后台长任务；图片编辑保存 Native 附件回写优先与只读下载兜底；
   - **保留 Picker（1.4.51 文件选择器）**：优先调用 `showOpenFilePicker`，用户主动取消时不触发二次回退弹窗；
   - **保留 Touch（1.4.50 多指触控与移动端边界）**：多指触控防污染隔离直至全指离开，跨区域三指防误触侧边栏；明确移动端纯 HTTP 下 OS 退出/返回限制不作过度宣称。
