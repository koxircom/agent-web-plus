# Agent Web Plus 1.4.72

本次发行包含此前尚未公开的 1.4.71 改动及 1.4.72 修复。

- 浏览器标签页外观有独立设置入口，可配置标题模板与颜色。
- 批量删除任务运行时可取消尚未派发的项目；已派发项目保留实际执行结果。
- Codex WSL 历史读取支持旧版 Zstandard 压缩会话文件，不修改压缩原件。读取压缩历史需要系统 Zstandard 库。

发行附件包含已构建的 Web 应用、命令行入口、Codex 执行端、安装说明、包清单与 SHA-256 校验文件。GitHub 同时提供此标签对应的完整源码。安装时 npm 下载目标平台依赖，本包不是离线依赖镜像。

配套 Pi Agent SDK 版本为 1.5.0。升级时请保留已有数据和配置。
