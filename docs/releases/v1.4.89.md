# Agent Web Plus 1.4.89

本版聚焦目标任务全生命周期管理、排队与会话状态机死锁消除，以及多项交互与边界体验的深度加固：

- **目标（Goal Mode）删除与生命周期闭环**：
  - 目标卡片正式新增专属【删除】操作按钮，无论处于进行中、等待继续、已暂停还是已完成，均支持一键删除；
  - 后端 `/composer-goal` 命令与 RPC 协议全面支持 `delete` / `clear` 操作，删除后立即清空目标与计时器，平滑恢复为普通模式，旧目标上下文不再污染后续会话；
  - 自动修复历史会话中任务已完成但旧目标长期滞留无法清理的问题。
- **排队消息死锁状态彻底解除**：
  - 对排队消息在发送失败或待确认（unknown）状态下的删除与移回输入框操作解绑禁用限制，确保用户在任何异常情况下均拥有一键删除或撤回重编的最高控制权；
  - 拖拽调整顺序支持右键中断安全取消，排队图片画廊弹窗退出时确保背景滚动条可靠还原。
- **输入框与通知横条清理机制加固**：
  - `ModelErrorBanner` 补齐自闭环关闭与 Dismiss 机制，模型 429 或网络报错横条支持随时一键关闭；
  - `/compact` 压缩结果与报错横条增加关闭按钮，并在发送新消息时自动淡出清理；
  - 修复输入框零宽字符发送假死、历史记录导航换行高度自适应及长代码超宽撑裂布局问题。
- **侧边栏与移动端手势优化**：
  - 会话搜索框在按 Escape 时支持一键退出收拢；
  - 会话重命名输入增加多余换行与制表符清洗；移动端文字选区存在时自动避让侧边栏滑出手势；
  - 会话右键长按菜单支持触屏滚动与空白点击自动安全关闭，彻底杜绝悬空漂移。

安装包包含预构建 Web 应用、命令行入口和 Codex 连接器；npm 安装时按目标平台获取依赖。完整源码通过本版本标签的 GitHub Source code ZIP 和 TAR.GZ 提供。`SHA256SUMS` 和 `SOURCE-FILES.sha256` 分别用于核验附件和源码。
