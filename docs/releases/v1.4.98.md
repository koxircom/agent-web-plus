# Pi Web v1.4.98 发行说明

## 验收更正（2026-11-07）

以下为当时的变更意图，不是通过的验收结论。用户截图及K80复测证实底部Chrome Touch to Search仍显示，tabIndex与callout未能屏蔽；连续跨段问题也未完成验收。按钮26→38、46→68、字体10→15均不是精确放大30%。后续修复以1.4.99候选及真实门禁回执为准，不将旧文档用作成功证据。

## 原变更概述（历史声明，已被上述实测更正）

1. **彻底屏蔽浏览器原生上下文菜单与 Touch to Search 搜索底栏**：
   - 给 `<body>` 根容器显式配置 `tabIndex={-1}`，结合语义角色抑制 Chromium 移动端识别无交互纯文本，彻底禁用 Chrome on Android 的点按搜索（Touch to Search / Google 搜索底栏）；
   - 在正文区域长按时无条件执行 `event.preventDefault()`，彻底阻止系统原生上下文菜单浮条（`复制 全选 网页搜索 分享 AI写作 朗读`）弹出；
   - 配合 `-webkit-touch-callout: none !important;` 保证只呈现应用专属工具条。

2. **工具条与按钮视觉尺寸放大 30%**：
   - 按钮最小高度放大至 38px，宽度放大至 68px；
   - 字体大小放大至 15px（字重 600，加粗饱满）；
   - 工具条圆角提升至 12px，手指点击热区大幅增加，触控质感与清晰度全面升级。
