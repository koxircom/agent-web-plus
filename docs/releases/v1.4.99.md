# Pi Web v1.4.99 候选变更（尚未发布）

- 移除消息队列 info/success 瞬时提示及其计时器，保留实际错误和二次删除确认。
- 原生选择工具条：触屏选区变化时立即隐藏点击区域，结束事件后捕获当前选区；不再用300ms静默推断原生手柄释放，不在touchstart销毁工具条。重复的同范围selectionchange不隐藏已完成工具条。
- 工具条定位避让选区两端手柄；范围占满可见消息区时只使用安全空隙，没有安全空间时不覆盖手柄。
- 移除无效的body tabIndex=-1及重复callout样式。网页contextmenu取消不等于禁用Chrome原生Touch to Search。

## 验收边界

候选正在隔离真实前端及Redmi K80上验收。结构测试、构建通过不代表连续多屏、快速反向、跨段起点漂移已全部修复；Windows Ego触控门禁仍需独立回执，缺失不得部署。

1.4.96～1.4.98历史说明中“DOM静止彻底解决漂移”“完全屏蔽Chrome搜索栏”“精确放大30%”均没有足够证据。1.4.98实际按钮高度38px、宽68px、字体15px不等于旧26px/46px/10px各自的1.30倍。此候选保留当前可读尺寸，不再作该百分比声明。
