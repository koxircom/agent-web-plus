# Agent Web Plus 1.4.57 发布说明（上线候选 / Release Candidate）

> **状态声明**：当前版本为 **1.4.57 上线候选（Release Candidate）**。先前版本处于待 idle 状态，未执行生产环境正式上线切换（no cutover / 未 deploy），当前生产环境旧版本仍为 1.4.49。保留先前候选版本（1.4.50、1.4.51、1.4.52、1.4.53、1.4.54、1.4.55、1.4.56）发布历史，依赖（deps）历史不作破坏性改动。明确移动端纯 HTTP 下系统级限制及文件选择器边界，严禁声称 OS picker 已解决。

## 本次核心维护与边界规范

1. **浏览器标签页标题设置服务端持久化与跨端实时同显（Server-Authoritative Browser Title Settings & SSE Sync）**
   - **服务端权威落盘（Server-Authoritative Persistent Settings）**：浏览器标签页标题设置改由服务端全局权威管理，统一落盘持久化至各自运行时的 `agentDir/agent-web-settings.json`（如 `~/.pi/agent/agent-web-settings.json`）；严禁将运行时配置写入编译产物或 `/app` 目录，彻底杜绝版本升级时配置被意外覆写；
   - **同一实例多端共享与 SSE 实时广播（Shared Across All Browsers & Realtime SSE Stream）**：同一实例（Same Instance）下的所有浏览器窗口、新标签页及移动端访问共享同一份标题设置，通过 SSE 事件流（`/api/ui-settings/browser-title/events`）实现全端毫秒级实时同显；
   - **显式保存/重置与 CAS 409 防并发覆盖（Explicit Save/Reset & CAS 409 Dirty Protection）**：客户端采用显式「保存」与「重置」操作；保存时携带版本号执行 CAS 校验，若检测到并发修改返回 HTTP 409 冲突，严密保护本地未保存的 dirty 状态不被静默冲掉；
   - **废弃客户端 localStorage 伪权威（localStorage Deprecated & No Auto-Migration）**：1.4.53 旧版 localStorage 本地单端实现正式被服务端权威架构取代；客户端 localStorage 不具备权威性，且严禁执行自动静默迁移以防脏数据反向污染服务端；
   - **多环境物理隔离与独立实例自治（Environment Isolation for 30141 / 30142 / Windows）**：群晖 30141 主实例、30142 协作实例以及 Windows 本地工作机依托各自独立的工作目录（`agentDir`）存储各自设置，实例间物理隔离，互不干扰、互不串台。

2. **保留既有候选不变量与边界规范（Preserved Invariants & Boundaries）**
   - **保留 Annotation（1.4.56 输入框引用注释徽标宿主）**：React 自身受控空宿主（`data-pi-native-annotation-host`），输入框网格内部位于附件下方文字前，排队队列之外，计数为 0 自动隐藏，不侵入底层序列化器；
   - **保留 Arrow（1.4.55 发送按键纯净向上箭头圆圈）**：右下角统一采用纯净向上箭头，去除数字 badge，底层排队机制与 ComposerQueue 列表完整保留；
   - **保留 Delete（1.4.54 用量治理与安全所有者锁）**：外部扫描与合并防丢用量，Web 异步无感调度，Seal/Fingerprint/Tombstone 一致性严格不放宽；
   - **保留 Title（1.4.53 浏览器标签自定义标题）**：通用设置支持自定义标签标题（`pi-browser-tab-title`），旧版 local 隔离实现正式被 1.4.57 服务端共享权威取代；
   - **保留 Goal 与 Image（1.4.52 控制流与图片回写）**：任务控制流先 State 后 Ctx Abort，Idle 挂起不误杀长任务；图片编辑保存 Native 附件回写优先与只读下载兜底；
   - **保留 Picker（1.4.51 文件选择器边界）**：优先调用 `showOpenFilePicker`，用户主动取消时不触发二次回退弹窗；恪守系统限制，不声称 OS picker 已解决；
   - **保留 Touch（1.4.50 多指触控防污染隔离）**：多指触控防污染隔离直至全指离开，跨区域三指防误触侧边栏；明确移动端纯 HTTP 下系统限制不作过度宣称。
