# Agent Web Plus 1.4.88

本版聚焦多端网络自愈、连接诊断监控、侧边栏布局加固及多执行引擎调度优化：

- **侧边栏与布局防折行加固**：优化极窄视口与折叠状态下的会话侧边栏状态栏与标签布局，强制保持单行不折行显示，提升 ExecutionEngineSwitcher 引擎切换组件的自适应渲染稳定性。
- **VPN 与网络重连智能自愈**：加固异地办公与隧道漫游环境下的 SSE 流与会话长连接弹性，引入状态编码探针与断线恢复重连机制，杜绝虚假心跳与连接挂起。
- **连接诊断监控系统**：新增 Connection Diagnostics 连接诊断系统，全面监控状态同步、会话加载与 Codex 上游通信，支持安全轮转与诊断报告导出。
- **Codex 队列与草稿状态流转治理**：优化离线会话草稿恢复、批量删除状态流转及跨设备队列调度。
- **ChatMinimap 视口性能优化**：提升超长会话小地图滚动交互流畅度与初始首帧加载速度。

安装包包含预构建 Web 应用、命令行入口和 Codex 连接器；npm 安装时按目标平台获取依赖。完整源码通过本版本标签的 GitHub Source code ZIP 和 TAR.GZ 提供。`SHA256SUMS` 和 `SOURCE-FILES.sha256` 分别用于核验附件和源码。
