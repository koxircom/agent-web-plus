# Agent Web Plus 1.4.90

本版针对系统全链路输入工作流、队列状态机、侧边栏导航、Markdown 渲染与移动端触控交互进行了 50 项系统级缺陷消除与深度加固：

- **输入框与富文本体验加固**：
  - 修复 Linux/Chromium 平台下中文拼音输入法确认按 Enter 误发消息的缺陷；
  - 快捷斜杠命令支持中文全角斜杠（`／`），免切输入法直接唤起；
  - 修复零宽不可见字符导致的发送按钮假亮与提交死锁；
  - 优化超长历史记录切换时的多行高度自适应贴合与换行自动视口滚动；
  - 增加对文件拖拽的全格式放行（代码、文档、压缩包），排除纯文本拖拽干扰。
- **排队消息与交互队列异常消除**：
  - 排队消息列表在 Windows 平台采用细窄滚动条规范（`scrollbar-width: thin`），防止遮挡右侧操作区；
  - 完善排队行在拖拽过程中遇到右键点击时的安全退出机制；
  - 排队图片画廊弹窗在关闭时严格还原背景滚动锁定，杜绝页面卡死。
- **侧边栏、搜索与导航治理**：
  - 侧边栏容器补齐 `min-height: 0` 保证手机横屏等极限视口下纵向滚动正常；
  - 新建会话按钮增加毫秒级防抖，杜绝双击产生多余空白会话；
  - 项目选择器长路径增加截断保护，防止撑破侧边栏；
  - 搜索关键词高亮逻辑消除正则 `lastIndex` 状态污染，保证多词匹配 100% 准确。
- **Markdown 渲染与主题交互**：
  - Mermaid 流程图在语法错误时增加一键切换至“查看原始代码”的快捷按钮，方便复制与纠错；
  - 优化嵌套 Blockquote 在暗黑模式下的多层透明度叠加，提升长文引用可读性；
  - 表格容器补齐 `-webkit-overflow-scrolling: touch` 支持超宽表格平滑横滑；
  - 设置弹窗打开期间严格锁定页面背景滚动，消除滚动穿透。

安装包包含预构建 Web 应用、命令行入口和 Codex 连接器；npm 安装时按目标平台获取依赖。完整源码通过本版本标签的 GitHub Source code ZIP 和 TAR.GZ 提供。
