# Pi Web v1.4.94 发行说明

## 变更概述

1. **移动端复制与引用工具条恢复**：
   - 修复此前版本在触屏环境下将 `scheduleSelection()` 无条件返回导致“复制”与“引用”工具条完全无法弹出的缺陷；
   - 引入 600ms 定时器防抖，在 Android 选择手柄拖拽过程中平稳等待选区稳定（settle），避免高频 DOM 与 React 状态重绘引发手柄跳动与反向全选；
   - 监听 `pointercancel` 事件，使长按触发系统选择手柄后依然能稳定捕获选区并唤出工具条；
   - 触屏环境下保留系统原生上下文菜单，实现系统剪贴板与应用工具条协同共存。

2. **手柄遮挡消除与净空间距**：
   - 移动端浮动工具条在选区底部保留 40px 手柄净空间距，消除工具条压在原生水滴选择手柄上方的遮挡问题；
   - 若超出视口底部，则安全回退至选区上方展示。

3. **输入框与页脚选区越界隔离**：
   - 在粗指针触屏环境下，对未聚焦的输入框（textarea / input / contenteditable）应用 `user-select: none !important` 隔离约束，防止长按或拖动手柄时选区向下跨入草稿框；
   - 输入框一旦被用户主动点击或聚焦，立即恢复原生 `user-select: text !important` 与正常的编辑、选词、复制与粘贴能力；
   - 消息页脚（包含发送时间与操作按钮）增加禁选约束，防止跨段拖动手柄时将时间戳文本误选入选区。

4. **引用注释框指针事件对齐**：
   - 将增强模块 04 中的外部点击保存监听由 `mousedown` 升级为 `pointerdown`，解决移动端长按其他文字时未能触发外部保存导致旧注释框残留悬挂的问题；
   - 外部指针保存时默认不强行聚焦草稿框，避免弹起软键盘。
