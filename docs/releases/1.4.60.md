## 本次核心维护与边界规范

1. **标题设置 SSE 事件流按 agentDir 共享 Watch 与引用计数，资源耗尽智能降级轮询（Per-agentDir Shared Watch with RefCount & Resource Exhaustion Fallback）**
   - **每 agentDir 共享单个 Watch 与引用计数（Per-agentDir Shared Watch & RefCount）**：多客户端 SSE 连接时，按各自 `agentDir` 共享单个文件系统监听器（fs watch），内部维护活跃连接引用计数（refCount）；首个连接建立时启动 watch，全部连接释放后安全注销 watch，杜绝多连接导致文件句柄与监听器无谓倍增；
   - **仅在系统资源耗尽时降级 1 秒共享轮询（Fallback to 1s Shared Polling Only on ENOSPC / EMFILE / ENFILE）**：正常状态下严禁无脑轮询（正常完全不使用轮询），100% 优先依赖基于事件的文件监听；仅当底层系统触发 `ENOSPC`（系统监听上限已达）、`EMFILE`（进程文件句柄耗尽）或 `ENFILE`（系统级句柄耗尽）等资源耗尽错误时，才平滑自动降级为每个 `agentDir` 1 秒间隔的共享轮询（1s shared polling）；一旦连接全关或恢复同样安全注销释放；
   - **系统底层零侵入与无需 sysctl 提权（Zero Kernel Intrusion & No sysctl Required）**：完全在应用层自愈收敛，无需修改宿主机 Linux 内核参数，不依赖 `sysctl -w fs.inotify.max_user_watches` 或 root 管理员提权，完美适配群晖 NAS 等各类受限容器环境。

2. **保留既有候选不变量与边界规范（Preserved Invariants & Boundaries）**
   - **保留 Timing（1.4.59 任务计时权威与队列/流转生命周期对齐）**：输入队列 followUp 实际消费重新计时，Steer 与 Tool Loop 保持同一任务实体及启动时间，子任务耗时紧跟统计展示（⏱️ `#38bdf8`）与估算前缀（`≈`）；
   - **保留 Queue（1.4.58 队列插入横线与手势边界）**：插入条目横线引导、防反弹机制、同一消息 metadata 完整归属、取消手势即时响应以及 token CAS 并发保护；
   - **保留 Title SSE（1.4.57 浏览器标签页标题设置服务端持久化与跨端实时同显）**：服务端全局落盘 `agent-web-settings.json`，多端 SSE 事件流实时同显，CAS 409 防并发覆盖；
   - **保留 Annotation（1.4.56 输入框引用注释徽标宿主）**：React 自身受控空宿主（`data-pi-native-annotation-host`），输入框内部位于图片下方文字前，排队队列之外，计数为 0 自动隐藏；
   - **保留 Arrow（1.4.55 发送按键纯净向上箭头圆圈）**：右下角统一采用纯净向上箭头，去除数字 badge，底层排队机制与 ComposerQueue 列表完整保留；
   - **保留 Delete（1.4.54 用量治理与安全所有者锁）**：外部扫描与合并防丢用量，Web 异步无感调度，Seal/Fingerprint/Tombstone 一致性严格不放宽；
   - **保留 Title（1.4.53 浏览器标签自定义标题）**：通用设置支持自定义标签标题，已由 1.4.57 服务端共享权威取代；
   - **保留 Goal 与 Image（1.4.52 控制流与图片回写）**：任务控制流先 State 后 Ctx Abort，Idle 挂起不误杀长任务；图片编辑保存 Native 附件回写优先与只读下载兜底；
   - **保留 Picker（1.4.51 文件选择器边界）**：优先调用 `showOpenFilePicker`，用户主动取消时不触发二次回退弹窗；恪守系统限制，不声称 OS picker 已解决；
   - **保留 Touch（1.4.50 多指触控防污染隔离）**：多指触控防污染隔离直至全指离开，跨区域三指防误触侧边栏；明确移动端纯 HTTP 下系统限制不作过度宣称。
