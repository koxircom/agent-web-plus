# Agent Web Plus 1.4.61

## 修复
- Codex API 模型目录未声明思考档位时，不再把空数组误解释为 `off`。沿用适配层既有 low/medium/high 选择策略；已声明的档位和 none/off 映射继续保留。该策略不是上游能力认证。
- 模型设置使用专属响应式布局：中等宽窗口保留列表/详情左右分栏，手机窄屏分配更大的列表区域，低高度时内容仍可滚动访问。
- 原生 AppShell 统一追踪多触点序列，在文件打开事件边界拒绝污染序列产生的兼容点击；支持宽触屏、逐指释放及取消后的恢复，保留鼠标、键盘及下一次单指操作。

## 验收口径
- 对 1.4.49 至 1.4.60 的功能逐项复核，区分当前候选定向测试、完整应用交互与生产只读证据。
- Android 系统文件选择器的退出体验和实体设备三指手势不得用 CDP 模拟冒充验收完成。
