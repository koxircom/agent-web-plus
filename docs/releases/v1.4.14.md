# Agent Web Plus 1.4.14

本版聚焦 Codex Web 体验与能力边界自查修复，彻底消除前端误报未支持操作与 501 风险，完善 Codex 会话菜单原生交互与状态读取语义。

## 核心改进

- **Codex Web 能力边界校正与 501 隔离**：
  - 准确界定 Codex 与 Pi 引擎能力差异，从 Codex 会话及工具菜单中安全隔离未原生支持的操作（如树状导航、分支派生及特定重载逻辑），杜绝因能力不匹配返回 501 报错。
  - 原生支持能力（如完整消息派生副本、当前会话引用等）100% 完整保留并受控执行。
- **Codex 会话菜单原生交互与真实反馈**：
  - 会话菜单新增原生会话路径复制支持，优先读取实际持久化路径；对非本地驻留或占位会话给出真实提示，杜绝伪造路径。
  - 原生重载会话调用真实重读语义与超时诚实提示，避免虚假成功反馈。
- **Codex CLI 状态读取与版本对比加固**：
  - 明确分离 CLI 已安装版本与运行中实例版本，比对发布版本时严格使用已安装 CLI 版本。
  - 优先执行本地轻量快速读取，外部更新检查失败或超时时保留已有本地版本信息，避免状态直接跌落为未知。
- **模块独立演化与连接器零漂移保障**：
  - 仅对 04 号侧边栏与会话管理增强模块进行定向优化，其余 7 个模块原始哈希与 1.4.13 完全一致。
  - 连接器 125 项源码哈希与 1.4.12 经严格审查的 Native 集成基线 100% 一致，复用既有离线验收资产。
- **20 分片质量门禁与安全闭环**：
  - 继承 19 个质量门禁分片并扩充至 20 分片，新增收敛 3 个真实无头浏览器场景与直接单元测试的 `release-codex-web-audit` 门禁。
  - 源码与归档经过完整敏感词与品牌层级审计，零敏感凭据泄漏。

## 安装与升级

```bash
npm install -g https://github.com/koxircom/agent-web-plus/releases/download/v1.4.14/agent-web-plus-1.4.14.tgz
agent-web --no-open
```
