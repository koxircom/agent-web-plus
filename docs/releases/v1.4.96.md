# Pi Web v1.4.96 发行说明

## 变更概述

1. **移动端触屏拖选手柄起始点（Anchor）跳选反向全选彻底根除**：
   - 确诊深层根因：此前版本在手柄拖拽过程中，若停顿微调或连续触发 `selectionchange`，会触发 `setQuotedSelection` 的挂载与卸载，导致 React 重新渲染并把浮层插入/拔出 DOM 树；Android Chrome 底层在手柄拖动中检测到 DOM Mutation 会自动触发锚点 Snap 保护，将起始手柄瞬间向上一大截弹跳到顶端；
   - 架构重构：引入 `isTouching` 全生命周期手势守卫（监听 `touchstart`/`touchmove`/`touchend`/`touchcancel`）。在用户手指按在屏幕上拖动手柄的整个过程中，**绝对禁止触发任何 React 状态更新或 DOM 节点拔插**，保证 DOM 树处于 100% 绝对静止态；
   - 手柄拖动停止且手指完全离开屏幕后（`touchend`），平稳等待 250ms 手柄稳定，再唤出浮动工具条；手指再次触碰屏幕时即时无感收起工具条，彻底消除手柄冲突与起始点跳选。
