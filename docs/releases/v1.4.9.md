# Agent Web Plus 1.4.9

本版汇总自 1.4.5 以来已经验收的 Codex、消息队列与文件浏览修复。

## Codex 模型与首条消息

- 新建会话首次发送使用输入框实际显示的默认模型及思考深度，不再继承执行端不同的默认模型。
- 创建与切换设置等待原生确认；确认失败时保留输入，不静默发送到其他模型。
- 创建等待期间更改模型或思考深度，首条消息等待最新选择确认后发送。
- 修复模型切换被迟到状态覆盖，以及共享线程最终回复未齐时提前显示完成的问题。

## 队列与草稿

- 排队消息使用请求身份关联，避免客户端与执行端队列重复显示。
- 编辑、召回与异常恢复使用统一草稿交接；原文持久化后才确认回执。
- 同文不同请求仍分别保留；回执丢失重试不重复恢复正文。

## 文件与工作区

- 新建 Codex 会话尚无会话 ID 时，文件列表、预览、下载、上传、Git 与原生 @ 文件补全正确携带执行引擎上下文。
- 同路径的 Pi/Codex 文件标签独立保存来源；内部链接继承源标签的工作区及引擎。
- 切换目录或引擎时隔离迟到的列表、搜索与上传响应，保留既有路径和权限边界。
- 增加 Codex 子 Agent 只读查看与受限工作区浏览、worktree 支持。

## 验证与兼容

- 17 项同指纹发布分片全部通过；模型相关定向检查 72 项通过。
- 桌面与手机验证覆盖完整网页首发、并发设置、失败保稿及文件浏览。
- 正式实例通过只读模型目录、文件列表/预览、Git、索引和权限边界检查；未发送生产测试提示词。
- 保留 `pi-web` / `agent-web` 命令、现有数据目录及 SDK 依赖。未更改全局默认引擎或已有用户线程设置。

## 安装

下载 `pi-web-plus-1.4.9.tgz`，校验 `SHA256SUMS` 后按现有升级流程安装。预构建包可直接安装；Codex 连接器源码也包含在仓库与发行包中，连接器更新需在执行端单独按部署文档操作。发布到 GitHub 不会自动升级其他运行实例。
