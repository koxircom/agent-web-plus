# Agent Web Plus 1.4.93

本版针对手机触屏文本选择反向全选、手柄错乱与跨块跳选缺陷进行深层治理，并在群晖 30141 正式部署上线：

- **触屏文本选择手柄反向跳跃全选彻底根除**：
  - 移除了 CSS 中 `.markdown-body *` 的后代通配符硬性修饰，恢复消息正文内部自然继承连续文本流，消除跨行内标签时手柄对后方内容的错误反向吸附；
  - 阻断移动端触屏环境下拖选手柄时高频 `selectionchange` 触发 React 组件重绘（re-render），彻底消除由于 DOM 重新对比导致 Android 系统选择引擎手柄丢失与范围跳乱的经典缺陷；
  - 严格保持顶部工具条、底部输入区与消息底栏元数据的 `-webkit-user-select: none !important;` 隔离，保证选区精准局限在单条消息正文之内。

安装包包含预构建 Web 应用、命令行入口和 Codex 连接器；npm 安装时按目标平台获取依赖。完整源码通过本版本标签的 GitHub Source code ZIP 和 TAR.GZ 提供。
