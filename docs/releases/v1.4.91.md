# Agent Web Plus 1.4.91

本版重点攻克移动端 Markdown 列表多位数序号裁切截断问题，并全面完成 100 项全链路排版渲染、输入工作流与多端视口异常的系统级治理：

- **Markdown 列表数字裁切彻底解决**：
  - 针对有序列表多位数序号（两位数/三位数，如 91~100+）在移动端由于 `overflow-x: hidden` 与固定 `padding-left: 22px` 导致的左侧十位数被切断问题，将左缩进扩充至 `32px`（移动端 `34px`），确保全视口下数字序号端正完整呈现；
  - 完善无序列表嵌套有序列表层级缩进；优化行内代码（Inline Code）长路径自动折行换行；优化嵌套 Blockquote 引用在暗黑模式下的可读性。
- **全链路 100 项交互体验与状态机收敛**：
  - 会话 404 加载失败时提供安全【新建会话】一键脱困通道；
  - 修复输入框在快速输入中文全角斜杠、零宽不可见字符及长历史消息时的多重边缘死锁；
  - 侧边栏长路径溢出截断保护与新建按钮防抖；
  - Mermaid 流程图语法报错时支持一键切换至“查看源码”。

安装包包含预构建 Web 应用、命令行入口和 Codex 连接器；npm 安装时按目标平台获取依赖。完整源码通过本版本标签的 GitHub Source code ZIP 和 TAR.GZ 提供。
