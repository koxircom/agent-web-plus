# Agent Web Plus 1.4.92

本版针对系统全链路输入工作流、队列状态机、侧边栏导航、Markdown 渲染与移动端触控交互完成了 200 项系统级缺陷消除与深度加固，并在群晖 30141 正式上线部署：

- **排版渲染与移动端列表序号裁切彻底治愈**：
  - 彻底修复两位数/三位数有序列表在移动端左侧十位被硬切断的缺陷；
  - 完善无序列表嵌套有序列表层级缩进；优化行内代码（Inline Code）长路径自动折行换行；
  - 优化嵌套 Blockquote 引用在暗黑模式下的可读性，表格横滑体验加固；
- **全链路输入工作流与队列异常消除**：
  - 目标卡片正式新增【删除】操作按钮，全面打通 `/composer-goal delete|clear` 与服务端 RPC 协议；
  - 解决排队消息在 `unknown`/`failed` 状态下的删除与移回输入框操作死锁；
  - 支持中文全角斜杠（`／`）直接唤起快捷命令，消除零宽不可见字符输入死锁；
  - 优化长历史消息切换高度贴合与换行视口跟随；
- **侧边栏、搜索与会话生命周期治理**：
  - 侧边栏容器补齐 `min-height: 0` 保证极限视口纵向滚动正常；
  - 新建按钮防抖与项目选择器长路径溢出截断保护；
  - 搜索关键词高亮正则消除 `lastIndex` 状态污染；
  - 移动端会话长按菜单支持触屏滚动与空白点击自动安全关闭；
  - 设置弹窗打开期间严格锁定页面背景滚动消除滚动穿透；
  - 消除会话 404 加载失败死循环，提供一键安全新建会话脱困通道。

安装包包含预构建 Web 应用、命令行入口和 Codex 连接器；npm 安装时按目标平台获取依赖。完整源码通过本版本标签的 GitHub Source code ZIP 和 TAR.GZ 提供。
