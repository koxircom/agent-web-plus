## 本次核心维护与边界规范

1. **用量治理与持久化根治限定（Usage Durability & Lock Invariants）**
   - **扫描与合并防丢用量（Scan Outside & Commit Merge）**：外部扫描与提交合并严格确保不丢失 usage 记录，保证增量事件与全局用量完整核算；
   - **安全所有者锁（Safe Owner Lock）**：锁机制严格遵循明确所有者归属，绝不按 TTL 超时盲目偷抢锁；
   - **Web 异步无感调度（Web Async Non-blocking）**：Web 异步处理保持事件循环通畅，绝不冻结 UI 或核心交互；
   - **原生防护严格不放宽（Seal / Fingerprint / Tombstone）**：封印（seal）、数据指纹校验（fingerprint）与墓碑机制（tombstone）严格执行安全一致性，绝不放宽校验规则与审计约束。

2. **基准性能实测与严谨声明（Benchmark Evidence & Realistic Boundaries）**
   - **实测性能数据**：在 56.66M 合成测试数据（synthetic 56.66M）下，实际提交耗时约 4.3s（actual commit ~4.3s），明确澄清此前 371ms 属于假基准（非 371ms 假 benchmark）；
   - **严谨声明恪守边界**：切勿夸大所有场景的百分比性能提升（勿夸所有 case 性能 %），绝不保证“彻底无异常”，恪守客观实测数据与真实边界。

3. **保留既有候选不变量与边界规范（Preserved Invariants & Boundaries）**
   - **保留 Title（1.4.53 浏览器标签自定义标题）**：通用设置（Settings -> General）支持自定义浏览器标签标题（`pi-browser-tab-title`），同源本地隔离，最高优先级且固定不被状态覆盖；
   - **保留 Goal（1.4.52 控制流与生命周期状态机）**：Pi 任务真实控制流不经 Prompt，暂停先 State 后 Ctx Abort，Idle 冻结挂起，绝不误杀 detached 后台长任务；
   - **保留 Image（1.4.52 图片保存与附件回写）**：图片编辑保存走 Native 附件回写优先，无 consumer 历史只读场景下显式报错并降级触发下载保护；
   - **保留 Picker（1.4.51 文件选择器）**：document 级别优先调用 `showOpenFilePicker`，用户主动取消时不触发二次回退弹窗；
   - **保留 Multitouch（1.4.50 多指触控与移动端边界）**：多指触控防污染隔离直至全指离开，跨区域三指防误触侧边栏；明确移动端在纯 HTTP 环境下的系统级 OS 退出/返回限制仍未解决，不作过度或宽泛宣称（不泛 claim）。
