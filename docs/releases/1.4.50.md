# Agent Web Plus 1.4.50 发布说明（上线候选 / Release Candidate）

> **状态声明**：当前版本为 **1.4.50 上线候选（Release Candidate）**，仅完成源码与版本维护，**尚未部署到正式或测试运行环境**；明确测试基于真实 CDP 触控仿真而非实体 physical OS，不声称覆盖所有三指硬件。

## 本次核心维护与边界修复

1. **多指污染隔离直到全指离开（Multi-Touch Contamination Guard）**
   - 修复触控手势中的多指竞争缺陷，引入多指污染状态跟踪：当屏幕检测到多个触控点（如双指或三指操作）介入时，立即标记污染状态并锁定后续单指手势识别。
   - 污染状态严格保持生效，直到屏幕上的全部触控点完全离开（全指释放）后方才重置手势判定状态机，彻底杜绝手指依次抬起时被误判为单指有效滑动的回归问题。

2. **跨区域三指防误开右侧会话导航（Cross-Region 3-Finger Navigation Guard）**
   - 针对跨屏幕区域的三指滑动进行严格拦截与手势隔离，防止因系统级多指手势（如截屏、应用切换等）误触发并意外拉出右侧会话导航抽屉。
   - 确立清晰的手势区域边界与意图判定，消除多指跨区域滑入引起的侧边栏非预期弹出。

3. **保留空白双击与常规滑动/工具栏手势（Gesture Invariants Preserved）**
   - 严格保留空白区域单指双击（single blank double tap）的既有快捷行为。
   - 保证常规单指左右横向滑动（swipe navigation）以及底栏工具栏（toolbar）区域的触控交互灵敏度与稳定性不受影响。

4. **完整保留 1.4.49 附件选择器所有改动（1.4.49 Picker Improvements Retained）**
   - 完整继承并保留 1.4.49 针对附件选择器的所有改进与边界修复：包含图片与视频媒体过滤（Media Filter）、Android 平台二进制流（`application/octet-stream`）与独立文件流解析、取消选择防丢失保护（取消不丢草稿及既有附件）以及附件与输入的单一所有者（Single Owner）调度机制。

## 验证与边界说明

- **真实 CDP 验证**：本轮多指拦截、手势隔离与空白双击断言均通过真实的 Chrome DevTools Protocol（CDP / Playwright browser touch emulation）模拟触控事件流验证。
- **物理机与硬件边界**：明确本次验证非实体物理操作系统（非 physical OS），不声称已在所有厂商和规格的三指触控硬件设备上完成测试。
