# Agent Web Plus 1.4.47 发布说明（上线候选 / Release Candidate）

> **状态声明**：当前版本为 **1.4.47 上线候选（Release Candidate）**，仅完成源码与文档一致性收敛，**尚未部署到正式或测试运行环境**；其余未完成模块保持渐进演进状态，**不宣称全部功能已完全 Native 整合**。

## 本次真实 Native 迁移改动

1. **Composer 队列工作流 Native 化重构**
   - 引入 `hooks/useComposerQueueBridge` 与 `lib/composer-queue-client`，解耦输入框与队列状态。
   - `components/ComposerQueue` 全面重构，增强对排队消息提取、编辑与取消的原生状态机驱动。

2. **文件上传与消息附件处理 Native 接入**
   - 新增 `lib/file-upload-client.ts` 与 `lib/message-file-attachments.ts`，支持统一附件上传与渲染通道。

3. **扩展状态栏与工具公开状态规范化**
   - 优化 `components/ExtensionStatusBar.tsx` 与 `lib/tool-public-status.ts`，精确反映真实运行时工具状态与加载指标。

4. **会话插件更新状态与会话徽标（Badges）**
   - 新增 `app/api/session-addon-updates/` 与 `lib/session-addon-updates.ts`，打通业务插件更新状态记录与会话展示标签。

5. **执行引擎版本与子代理计时**
   - 增加执行引擎版本切换测试与子代理多步骤耗时核验，提供更稳定的双引擎切换体验。

## 品牌与离线恢复页一致性

- 严格恢复 `public/offline.html` 离线字标与 `lib/branding.ts` 矢量的 816x186 几何事实源（64px、起始坐标 x1=620 等）。
- 保持 Service Worker 注销、CacheStorage 清除、HTTP 静态资源重载及离线留守重试脚本结构完整无损。
- 文档及安装链接统一对齐当前候选版本 `1.4.47`。
