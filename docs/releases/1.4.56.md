# Agent Web Plus 1.4.56 发布说明（上线候选 / Release Candidate）

> **状态声明**：当前版本为 **1.4.56 上线候选（Release Candidate）**。先前版本处于待 idle 状态，未执行生产环境正式上线切换（no cutover / 未 deploy），当前生产环境旧版本仍为 1.4.49。保留先前候选版本（1.4.50、1.4.51、1.4.52、1.4.53、1.4.54、1.4.55）发布历史，依赖（deps）历史不作破坏性改动。明确移动端纯 HTTP 下系统级限制及 OS picker 限制不作过度宣称（不能声称 OS picker 已修）。

## 本次核心维护与边界规范

1. **输入框引用注释徽标宿主与渲染层级（Composer Quote Annotation Badge Host & Layout）**
   - **真实 React 拥有空宿主（React-Owned Empty Host）**：引用注释徽标由 React 自身空宿主容器（`data-pi-native-annotation-host`）权威承载与管理，杜绝非受控 DOM 挂载混乱；
   - **输入框内图片下文字前精准拓扑（Inside Composer, Below Images, Before Text）**：宿主严格位于输入框（Composer / ChatInput）网格内部，排布在附件/图片预览下方、文本输入框（Textarea）之前；
   - **排队队列之外完全解耦（Outside Queue）**：引用注释徽标严格独立于任务排队队列（ComposerQueue），保持在 queue 之外；
   - **计数清零自动隐藏（0-Clear Hidden Invariant）**：当引用注释数量清空或为 0 时，徽标宿主自动隐藏，无多余空占位或残留节点；
   - **插槽独占不动底层序列化器（Slot-Owned Annotations & Untouched Serializer）**：由专有插槽/宿主单独管理 annotation 状态，不侵入、不改动底层消息序列化器（serializer）。

2. **保留既有候选不变量与边界规范（Preserved Invariants & Boundaries）**
   - **保留 Send & Queue Badge（1.4.55 纯净向上箭头圆圈与排队完整保留）**：右下角发送按键统一采用纯净向上箭头（Up Arrow），去除旧版按钮上的数字徽标；底层排队机制与 ComposerQueue 列表完整保留；
   - **保留 Usage Lock（1.4.54 用量治理与安全所有者锁）**：外部扫描与合并防丢用量，Web 异步无感调度，Seal/Fingerprint/Tombstone 一致性严格不放宽；
   - **保留 Title（1.4.53 浏览器标签自定义标题）**：通用设置支持自定义标签标题（`pi-browser-tab-title`），同源本地隔离，最高优先级且固定不被状态覆盖；
   - **保留 Goal 与 Image（1.4.52 控制流与图片回写）**：任务控制流先 State 后 Ctx Abort，Idle 冻结挂起不误杀长任务；图片编辑保存 Native 附件回写优先与只读下载兜底；
   - **保留 Picker（1.4.51 文件选择器边界）**：优先调用 `showOpenFilePicker`，用户主动取消时不触发二次回退弹窗；恪守系统限制，不声称 OS picker 已修；
   - **保留 Touch（1.4.50 多指触控与移动端边界）**：多指触控防污染隔离直至全指离开，跨区域三指防误触侧边栏；明确移动端纯 HTTP 下系统限制不作过度宣称。
