# Agent Web Plus 1.4.48 发布说明（上线候选 / Release Candidate）

> **状态声明**：当前版本为 **1.4.48 上线候选（Release Candidate）**，仅完成源码与版本可追溯性维护，**尚未部署到正式或测试运行环境**；文档与代码标明预发布候选状态。

## 本次核心维护与边界修复

1. **会话状态排他锁迁移（State Lock Migration）与死锁 Fail-Closed 机制**
   - 状态提交（`commit` / `commitSync`）由早期的进程内 Promise 串行锁彻底迁移至基于目录原子争用的排他锁（`agent-state-mutex.cjs`）。
   - 支持跨进程互斥保护与陈旧锁（stale lock）安全回收。
   - 在并发死锁或锁异常时执行严格的 Fail-Closed 策略，拒绝脏写入并保持状态文件完整性。

2. **双路权威（Dual-Authority）治理**
   - 确立后端状态存储（State Store）为 session tags 与会话属性的权威事实源。
   - 修复前端本地缓存与后端 journal 之间的双路冲突，确保多客户端并发时状态单向收敛，彻底杜绝数据覆盖或空列表抹除。

3. **旧 Tab 兼容与 Outbox 发件队列维护边界**
   - 针对浏览器历史多 Tab 遗留会话状态进行隔离与清理，防止旧 Tab 脏数据回写。
   - 规范 Outbox 队列的幂等提交边界，保证消息排队提取、恢复与网络重放时状态可追溯且无重复提交。
