# Pi Web v1.4.97 发行说明

## 变更概述

1. **彻底屏蔽浏览器原生工具条与触控搜索底栏**：
   - 在正文区域长按文字时，通过 `contextmenu` 事件的无条件 `event.preventDefault()` 彻底屏蔽 Android Chromium 系统自带的长按黑色长条菜单（`复制 全选 网页搜索 分享 AI写作 朗读`）；
   - 彻底阻止系统 `ActionMode` 唤起，从而根除 Chrome for Android 的底部“点按即可查看搜索结果”（Touch to Search / Google 搜索横幅）；
   - 配合 `-webkit-touch-callout: none !important;` 样式，全方位净化移动端选区视觉，仅保留应用专属的“复制”和“引用”悬浮工具条。

2. **复制与引用工具条字体与按钮同步放大 30%**：
   - 字体大小由原 11px/10px 同步放大 30% 至 **14.5px**（字重 550），阅读更清晰直观；
   - 按钮最小高度由 26px 放大 30% 至 **35px**，最小宽度由 46px/50px 放大 30% 至 **62~65px**；
   - 按钮内边距调整为 `6px 14px`，圆角提升为 `12px`，在 2K 等高分移动屏上大幅增强触控点击热区与操作舒适度。
