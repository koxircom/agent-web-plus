# Agent Web Plus v1.4.0

## 本次更新

- 品牌统一为 Agent Web Plus，Pi Agent 与 Codex 继续共用同一套前端。
- 保留 `pi-web` 旧命令，增加 `agent-web`；已有会话、置顶、设置和旧配置目录继续使用。
- 内置 Codex 执行端，提供本机 CLI 连接及远程兼容入口；配置方法见项目文档。
- 纳入会话导航、队列恢复、目标与计划、用量统计及运行版本区分等已有改进。
- 修复 Codex 完成后最终回复可能需要刷新才出现的问题：工具详情按需读取，正文读取失败保留批次重试。
- 发布统一使用已登记容器认证；源码、发布说明和最终附件在上传前执行脱敏扫描，下载回读 SHA256 一致后公开。

## 安装或升级

要求 Node.js >=22.19.0。内部 npm 包名保留 `@agegr/pi-web`，不发布到公共 npm 注册表。

```bash
npm install -g https://github.com/koxircom/agent-web-plus/releases/download/v1.4.0/pi-web-plus-1.4.0.tgz
agent-web --no-open
# 原命令继续可用：pi-web --no-open
```

Codex 模式需要用户自己的 Codex CLI 及登录配置。按 [Codex 配置文档](https://github.com/koxircom/agent-web-plus/blob/v1.4.0/docs/codex-engine.md) 设置执行端；项目不会附带个人认证或聊天数据。

已有数据默认继续读取 `~/.pi/agent`，兼容原有数据目录变量。请保留原配置，并按自己的维护流程重启服务；GitHub 发布不会自动升级已有运行实例。

附件提供安装包和 SHA256SUMS。校验方式：`sha256sum -c SHA256SUMS`。

本版本经过发布关卡、隔离安装及关键页面检查；实体手机弱网行为仍需在实际设备上持续观察。
