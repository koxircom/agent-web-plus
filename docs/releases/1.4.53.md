# Agent Web Plus 1.4.53 发布说明（上线候选 / Release Candidate）

> **状态声明**：当前版本为 **1.4.53 上线候选（Release Candidate）**。先前候选版本（1.4.50、1.4.51、1.4.52）在等待上线期间宿主任务因 WAITING_IDLE 状态结束，未执行生产环境正式上线切换（no cutover），在本 Release（1.4.53）中统一合并上线。保留 `1.4.50.md`、`1.4.51.md`、`1.4.52.md` 作为候选发布历史，依赖（deps）历史不作破坏性改动。明确移动端在纯 HTTP 环境下的系统级 OS 退出/返回限制仍未解决，不作过度宣称。

## 本次核心维护与边界规范

1. **通用设置浏览器自定义标签标题（Browser Tab Title Customization）**
   - **Settings General 本地同源持久化**：在通用设置（Settings -> General）中提供自定义标签标题输入框与一键重置按钮，配置自动限制在本浏览器同源本地（`localStorage`，key: `pi-browser-tab-title`），不向服务端泄漏；
   - **留空即时恢复默认**：输入留空或点击重置操作立即清除存储项，无缝回退至默认动态标题（`composeEnhancementWindowTitle`）；
   - **80 Unicode 码点上限与字符清洗**：输入严格清洗换行符（`\r`, `\n`）与 C0/C1 控制字符，并实施最多 80 个 Unicode 码点（80 code points）的安全截断保护；
   - **跨同源多标签页实时同步（Cross Same-Origin Tabs）**：监听浏览器原生 `storage` 事件配合 React `useSyncExternalStore` 响应式状态流，所有已打开的同源标签页实时联动更新；
   - **自定义标题优先且固定（Custom 固定不被 Status 覆盖）**：配置生效后自定义标题拥有最高优先级并固定显示，绝不被运行时后台任务状态或插件动态标题覆盖。

2. **保留 1.4.52 控制流与图片回写规范（Preserved 1.4.52 Invariants）**
   - **Pi 任务真实生命周期与控制通道**：Pi 控制流严格走原生状态通道（先 state 后 ctx abort，idle 冻结挂起，绝不误杀 detached 后台长任务），不依赖 LLM Prompt 干预；
   - **图片保存 Native 附件回写与只读兜底**：图片编辑保存优先回写会话附件，无 consumer 或历史只读会话下显式报错并降级触发下载兜底。

3. **合并 1.4.50/1.4.51 触控与文件选择器修复（Merged 1.4.50/1.4.51 Invariants）**
   - **1.4.51 文件选择器旧优先与取消防二次回退**：document 级别优先调用 `showOpenFilePicker`，用户主动取消时不触发二次回退弹窗；
   - **1.4.50 多指触控防污染隔离**：多指触控污染隔离直至全部手指离开屏幕，跨区域三指手势防误触侧边栏；
   - **移动端边界恪守**：继续说明移动端在纯 HTTP 下的系统级退出/返回（OS back/exit）限制仍未解决，不泛 claim。
