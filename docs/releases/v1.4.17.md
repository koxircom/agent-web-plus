# Agent Web Plus 1.4.17

本次为 1.4.15–1.4.17 累计发布，包含 Codex 与 Pi 用量账本价格估算、原生已归档会话多引擎治理、新会话品牌 64px 响应式自适应以及已验证配套 Pi Agent 1.4.0 环境支持。

## 累计改进

### 1. Codex 费用参考估算与 24 小时模型目录更新（1.4.15）
- **用量与费用参考估算**：
  - 用量统计面板支持 Codex 与 Pi 同口径参考价估算，细分呈现输入、输出及缓存读写费用。
  - 明确标注为参考估算而非正式账单；参考价格补算仅用于显示，不改写已保存的用量事件及原始费用。
  - 若部分原生历史用量日志不可用或格式不匹配，系统仅覆盖可读用量，不保证完整账单，保证界面稳定不崩溃。
- **24 小时模型目录按需更新**：
  - 针对 Codex 参考价源（openai-codex）按需复用原生目录，在后台按 24 小时周期校验并更新参考价缓存（不代表全 provider 后台轮询）；冷启动即刻返回存量缓存，失败时优雅降级保旧，避免前台请求阻塞。

### 2. 原生已归档会话多引擎治理（1.4.16）
- **多引擎归档切换与异步分页**：
  - 设置页「已归档」面板支持「Pi Agent / Codex」双引擎切换，根据当前会话环境智能推断默认视图。
  - Codex 归档模式通过原生接口异步分页读取已归档会话，支持滚动加载更多与手动刷新。
- **安全操作与原生确认**：
  - 支持 Codex 归档会话单选、多选批量还原与彻底物理删除；还原/删除须收到原生确认回执，删除保留界面二次确认。
  - 严密隔离引擎数据边界：Codex 归档治理完全走原生接口，不污染 Pi 本地 manifest 与配置。

### 3. 品牌字标响应式与 SDK 升级（1.4.17）
- **新会话品牌 64px 响应式优化**：
  - 欢迎页面字标自适应比例优化为 64px 级，标题容器固定 180/200px 响应式高度；本版已通过 390px 移动端与 1280px 桌面端实测验证，两引擎冷加载与切换几何通过，不作未测视口的无限保证。
- **配套已验证 Pi Agent 1.4.0**：
  - 配套已验证 Pi Agent 1.4.0 运行环境（包含 `@earendil-works/pi-agent-core`、`@earendil-works/pi-ai`、`@earendil-works/pi-coding-agent`、`@earendil-works/pi-tui` 及 CLI 1.4.0）。

## 安装与升级

需要 Node.js **22.19.0 或更新版本**（推荐 Node.js 24 LTS）；使用 Codex 执行端还需 Python **3.11+** 及用户自己的 Codex CLI 与登录配置。

```bash
npm install -g https://github.com/koxircom/agent-web-plus/releases/download/v1.4.17/agent-web-plus-1.4.17.tgz
agent-web --no-open
# 兼容旧命令：pi-web --no-open
```

附件包含安装包及 `SHA256SUMS`。升级前请保留既有数据目录；本项目不包含用户私人凭据与会话历史。
