# Agent Web Plus

**Agent Web Plus** 是包含 **Pi Web Plus** 与 **Codex Web Plus** 两大入口的统一浏览器工作台。两者共享同一个工作台前端与后台服务实例，无需分别安装；左上角切换菜单实际项显示为 **Pi Agent** 与 **Codex**。

当前最新版本为 **1.4.17**，配套已验证 Pi Agent **1.4.0**（四 SDK 与 CLI）。本发行支持 Codex 费用参考估算（参考价格补算仅用于显示，不改写已保存的用量事件及原始费用；缺历史不补造）、openai-codex 参考价目录 24 小时按需复用更新、原生归档设置页多引擎治理（双引擎切换、异步分页、手动刷新；还原/删除须收到原生确认回执，删除保留界面二次确认），以及新会话 64px 品牌字标响应式布局自适应。

中文完整安装、Codex 配置和改名兼容说明统一维护在 [README.md](README.md)，避免两份配置文档出现差异。
